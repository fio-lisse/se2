Automatische tests voor B01

Draai vanuit de hoofdmap van de repository:

node se2/b01/tests/voorraad.test.cjs

Dit script gebruikt de echte voorraadregels uit MVP 3 Code.gs. In plaats van een echte Google Sheet gebruikt het een kleine nepsheet. Zo heb je geen Google-account nodig. De bestaande MVP's blijven hetzelfde.

Het programma controleert automatisch:

  • Uitlenen bij voorraad 1: gelukt, voorraad wordt 0.
  • Nogmaals uitlenen bij voorraad 0: niet gelukt, voorraad blijft 0.
  • Terugbrengen bij voorraad 0: gelukt, voorraad wordt 1.
  • Na een wijziging wordt de Sheet weggeschreven.

Bewust falende test: ‘Een tweede uitlening lukt toch bij voorraad 0.’ Dit is expres een verkeerde verwachting. De test toont FOUT (bewust) omdat de echte regel de tweede uitlening weigert. Dat laat zien dat een test een onjuiste verwachting kan ontdekken. De opdracht eindigt alleen met een foutcode als een onverwachte controle mislukt.

Voorbeeld van de uitgevoerde test:

GOED: Van 1 naar 0: uitlenen lukt.
GOED: Bij 0 blijft de voorraad 0: tweede uitlening mislukt.
FOUT (bewust): Een tweede uitlening lukt toch bij 0 (opzettelijk verkeerde verwachting).
  Zo zie je dat een test een verkeerde aanname ontdekt.
GOED: Van 0 naar 1: terugbrengen lukt.
GOED: Sheet wordt weggeschreven bij beide wijzigingen.
4 controles goed, 1 bewust fout, 0 onverwachte fouten.

De test controleert de voorraadregels met een nepsheet, niet een live Google Sheet of een gepubliceerde webapp. Github Actions voert dezelfde controles uit. Bekijk de rode run met een verkeerde verwachting en de groene run na herstel.
